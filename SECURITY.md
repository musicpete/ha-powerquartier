# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's
private vulnerability reporting instead: **Security → Report a vulnerability**
in this repository.

Include what is affected, how to reproduce it and the version. Never include
credentials, tokens, customer numbers, invoices or other personal data in a
report or issue; replace them with placeholders.

You will get an answer within 7 days.
